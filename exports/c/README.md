# CHOWK policy in C

`chowk_policy.h` is the published CHOWK policy as dependency-free C99: the weights as a `float` array and a forward pass that uses only addition, multiplication and comparison, in double precision and in the same order as the TypeScript inference. It is the kind of code a signal-controller cabinet could run; no such hardware was tested.

`chowk_cases.h` holds observations recorded on a validation seed plus random inputs, with the TypeScript outputs as exact IEEE-754 bit patterns. `check.c` compares every output and reports the time per decision.

```sh
npm run policy:c
cc -std=c99 -ffp-contract=off -O2 exports/c/check.c -o chowk-check
./chowk-check
```

CI regenerates the export, fails if it differs from the committed files, and runs the check. All three files are generated by `packages/controllers/tools/export-c.ts`.
